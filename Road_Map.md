# Project Vision: HomeEdu MVP

## 1. Введение и Миссия
**HomeEdu** — это веб-платформа для семейного образования, которая помогает родителям структурировать учебный процесс, а детям — проходить его в удобном темпе с понятной системой мотивации и контроля.

**Миссия MVP:** Создать базовый, но полностью рабочий инструмент для учета прогресса, выдачи домашних заданий, проведения контрольных и выставления оценок для детей 4-6 классов (10-12 лет).

## 2. Целевая аудитория и UX-принципы
### Пользователи:
1. **Родитель (Администратор/Учитель):** Управляет контентом, создает уроки и тесты, отслеживает прогресс, выставляет оценки.
2. **Ребенок (Ученик, 10-12 лет):** Выполняет задания, проходит тесты, загружает файлы, видит свой прогресс.

### UX/UI Принципы:
* **Баланс возраста:** Интерфейс не должен быть «детским» (как для младших классов), но требует высокой визуальной обратной связи, четкой навигации и геймификации (прогресс-бары, бейджи).
* **Режим «Фокус»:** При выполнении теста или урока интерфейс очищается от лишних элементов.
* **Mobile First & PWA:** Дети часто учатся с планшетов. Приложение должно работать как PWA (установка на главный экран).

## 3. Функциональные требования (MVP)
### Для Родителя:
* Конструктор уроков (текст, медиа, встраивание видео).
* Конструктор тестов (один вариант, несколько вариантов, короткий ответ).
* Задания с загрузкой файлов (фото тетради, проекты).
* Дашборд прогресса ребенка (тепловая карта, процент выполнения).
* Журнал оценок.

### Для Ребенка:
* Лента уроков и домашних заданий.
* Интерфейс прохождения тестов с таймером (опционально).
* Загрузка ответов (файлы/фото).
* Личный прогресс-бар по предметам.

## 4. Техническая Архитектура
Проект построен по принципу **разделения ответственности** и **Headless-подхода**.

### Стек технологий:
* **Публичный фронтенд (Лендинг, SEO):** Next.js + TypeScript (SSR/SSG).
* **Приватный фронтенд (LMS, Дашборды):** React + TypeScript + Vite (CSR).
* **UI и Дизайн-система:** Radix UI (Headless) + Tailwind CSS + Storybook.
* **State Management:** Zustand (для UI и локального состояния LMS).
* **CMS (Управление контентом):** Payload CMS (Headless CMS для хранения уроков, текстов, медиа).
* **Бэкенд (Бизнес-логика):** Node.js + NestJS (авторизация, расчет прогресса, проверка тестов, оценки).
* **Rich Text Editor:** TinyMCE (для конструктора уроков).

### Схема взаимодействия:
1. **Payload CMS** хранит и отдает учебный контент (уроки, тексты, медиа) через REST/GraphQL API.
2. **NestJS** хранит учебную логику (пользователи, связи ученик-родитель, прогресс, ответы на тесты, оценки) и предоставляет REST API.
3. **Next.js** (публичная часть) обращается к Payload и NestJS для SEO-страниц.
4. **React+Vite** (приватная часть) обращается к Payload (за контентом урока) и NestJS (за действиями: "сохранить ответ", "получить оценку").
